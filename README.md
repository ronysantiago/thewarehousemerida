# thewarehousemerida
Plataforma digital integral para The Warehouse, complejo industrial estratégico en Mérida. Incluye landing page comercial y portal de gestión interna para arrendatarios, facilitando control de accesos, monitoreo de seguridad 24/7, servicios operativos, respaldo energético (500 kVA) y conexión con el ecosistema productivo local.
